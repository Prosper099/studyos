Connect StudyOS to your Firebase project

Five steps, then the app runs fully online.

⚠️ Most common problem: the database exists but its rules still deny everything, so preferences and quiz results cannot save. If you see "Firestore is unavailable", publish the rules below — it takes about 30 seconds.
  1. 1. Create a project at console.firebase.google.com, then add a Web app (the </> icon) and copy the config object.
  2. 2. Paste the values into the firebaseConfig object near the top of the type="module" script.
  3. 3. In Authentication → Sign-in method, enable Google (add your support email when prompted).
  4. 4. In Firestore Database, create a database, then publish the rules below.
  5. 5. If you deploy to your own domain, add it under Authentication → Settings → Authorised domains.
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}

Document shape written by the app: users/{uid} → { name, email, classLevel, targetExam, subjects[], onboarded, streak, lastActiveDate, quizStats, quizPerformance }
